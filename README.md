# Sepsis Prediction & Interpretability Tool 🏥

  An AI   clinical decision support system (CDSS) designed to predict sepsis risk using machine learning. This project implements a **Logistic Regression** model optimized with a custom **Safe Preprocessing** pipeline and interpreted via **SHAP (SHapley Additive exPlanations)**.

 2. Project Overview
Sepsis remains a leading cause of mortality in hospitals worldwide. This tool aims to provide healthcare professionals with a predictive risk score and, more importantly, a transparent explanation of *why* a patient is flagged as high-risk.

Key Features
Predictive Modeling: Logistic Regression model
Feature Engineering: Custom preprocessing for clinical lab values and vitals.
Explainability:** Integrated SHAP plots to visualize feature importance for individual patient predictions.
Deployment:** Built with Streamlit for a real-time, interactive user interface.

 3. Repository Structure
sepsis3_app.py`: The main Streamlit application script.
sepsis_lr2_safe_preproc_v03_model.joblib`: The serialized model artifact.
requirements.txt`: List of Python dependencies.
data/`: (Optional) Sample anonymized clinical data for testing.
